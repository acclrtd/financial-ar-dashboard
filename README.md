# 📊 Financial & Accounts Receivable Analytics Dashboard

## 🌟 Project Overview
This project features a comprehensive Power BI solution developed for **JRJGB Construction Development & Trading Corporation**. It provides a dual-layered view of corporate health: tracking high-level sales performance and managing critical liquidity through Accounts Receivable aging.

## 🛠️ Technical Implementation
I utilized the following Power BI capabilities to build this project:

* **Data Transformation:** Cleaned and structured raw financial data using **Power Query**.
* **DAX Measures:** Developed custom calculations for:
    * **Total Sales:** Aggregating revenue across entities.
    * **Overdue Tracking:** Identifying invoices past their 2026 due dates.
* **Interactive UI/UX:** * Implemented **Page Navigation** (Home/Info buttons) for a professional app-like feel.
    * Added **Slicers** for Fiscal Year, Entity, and Month for granular filtering.

## 📈 Business Insights & Impact
Based on the data visualized:
* **Revenue Concentration:** Client **SEPI** is a major stakeholder, contributing **36.14%** of the total amount.
* **Collections Status:** There is currently **1.29M** in total due/overdue amounts that require immediate attention.
* **Monthly Trends:** Significant growth was observed toward the end of the year, peaking in **December**.
